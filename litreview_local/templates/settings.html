Where your library is

{{ data_dir }}

Everything is in that folder: the database (litreview.db), the PDFs (pdfs), these settings (settings.json), the backups and the logs. {% if from_env %}It was chosen with LITREVIEW_DATA_DIR.{% endif %}

Moving it somewhere else
  1. Quit LitReview (the button below).
  2. Move the whole folder where you want it.
  3. Tell LitReview where it is now, with the LITREVIEW_DATA_DIR setting: {% if platform == 'win32' %} open Command Prompt and run setx LITREVIEW_DATA_DIR "D:\Research\LitReview" (with your folder), then start LitReview again. {% elif platform == 'darwin' %} add the line export LITREVIEW_DATA_DIR="$HOME/Documents/LitReview" (with your folder) to the file ~/.zprofile, then start LitReview again. {% else %} set it in your shell's profile, e.g. export LITREVIEW_DATA_DIR="$HOME/LitReview". {% endif %} Starting LitReview with --data-dir "<folder>" does the same.
  4. If you use Claude Desktop, press Add LitReview to Claude Desktop on Getting started again afterwards, so Claude Desktop knows the new place too.

Without the setting, LitReview uses {{ default_data_dir }}.

Backups

Each time LitReview starts, it copies the database into {{ backups_dir }} and keeps the last ten. {% if backups %}The newest is from {{ backups[0].when.strftime('%d %b %Y, %H:%M') }} ({{ plural(backups | length, 'copy', 'copies') }} in all). {% else %}There are none yet: the first is made the next time LitReview starts.{% endif %}

The backups hold the database, not the PDFs: to keep everything, copy the whole library folder. To go back to a backup, quit LitReview, put the backup in place of litreview.db (renamed to that), and start LitReview again.

Logs, if something goes wrong: {{ logs_dir }}

Quit LitReview

Stops the app. Everything is saved as you go, so nothing is lost, and work in progress carries on the next time it starts. Claude Desktop starts LitReview again by itself when you ask it something about your review.
